## 🏆 Projet phare : Analyse de positionnement prix — Marché luxe & retail

**En une phrase :** analyse du positionnement prix sur 120 produits mode & luxe prouvant que le luxe ne se brade pas.

- 120 produits analysés · Prix médian : 2 869 USD · Remise moyenne pondérée : 25,26 %
- Insight clé : corrélation négative prix/remise — plus le prix monte, moins la remise est forte
- Écart de prix : facteur ~20 entre segment accessible et segment luxe pour un même type de produit
- Segmentation : 3 segments (Accessible / Mid / Luxe) par catégorie (montres, maroquinerie, textile)
- Stack : Python (collecte API) · SQL · Looker Studio
